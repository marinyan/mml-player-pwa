# MML Player PWA

iPhone Safariで使える、オフライン対応のMMLプレイヤーです。バックエンド、DB、
ログイン機能を使用せず、静的ファイルだけで動作します。

- 公開URL: https://marinyan.github.io/mml-player-pwa/
- ライセンス: BSD-2-Clause

## 主な機能

- Web Audio APIによる複数トラック再生
- txt/mmlのインポート・エクスポート
- 44.1kHz / 16bit PCM / stereo WAVエクスポート
- GM音色トラックのMIDI（SMF Format 1）エクスポート
- 内蔵音色、GM音源風プリセット、MML内2OP/4OP FM音色定義
- リピート、拍子、小節線、タイ/スラー、連符、インライン和音
- パン、ゲートタイム、クレッシェンド、ディミヌエンド
- `localStorage`による自動保存・復元
- Service Worker + Cache Storageによるオフライン起動
- UIから分離したMML parser/compilerとVitestテスト

## 使い方

1. エディタへMMLを入力します。
2. `Play` で再生します。
3. `Stop` で停止、`Rewind` で先頭へ戻ります。
4. Fileメニューからデモ曲ロード、ファイル入出力を行います。

iOS Safariの制約に対応するため、`AudioContext` は必ずユーザーが `Play` を
押した後に開始します。

Positionは `現在位置 / 曲全体の長さ` を秒単位で表示します。

## Fileメニュー

| 項目 | 内容 |
| --- | --- |
| `Load demo song` | 内蔵デモ曲を読み込みます |
| `Import txt/mml` | txt/mmlファイルを読み込みます |
| `Export mml` | ファイル名を指定してMML全文をUTF-8で保存します |
| `Export WAV` | ファイル名を指定してステレオWAVを保存します |
| `Export MIDI` | ファイル名を指定してGM音色トラックをMIDIで保存します |

現在のMMLが未エクスポート、または最後のMMLエクスポート後に変更されている
場合、デモ曲ロードやファイル読み込み前に警告します。

保存済み状態を更新するのは `Export mml` だけです。WAV/MIDIエクスポートは
MML本文の保存済み状態を変更しません。

## MMLクイックリファレンス

MMLコマンドと音名は大文字・小文字を区別しません。空白と改行は無視します。

| 記法 | 内容 |
| --- | --- |
| `T<number>` | テンポ |
| `O<number>` | オクターブ |
| `L<number>` | デフォルト音長 |
| `C D E F G A B` | 音符 |
| `R` | 休符 |
| `#` / `+` / `-` | 半音上げ / 半音下げ |
| `.` | 付点 |
| `<` / `>` | オクターブを下げる / 上げる |
| `V<number>` | 音量 0〜15 |
| `cresc.` / `dim.` | 音符ごとに音量を1段階増加 / 減少 |
| `P<number>` | パン -1.0〜+1.0 |
| `Q<number>` | ゲートタイム 1〜8 |
| `@<number>` | 内蔵音色またはMML内FM音色 |
| `@gm<number>` | GM音源風プリセット `gm1`〜`gm128` |
| `&` | タイ / スラー |
| `,` | トラック区切り |
| `//` | 行コメント |
| `#TIME n/d` | 拍子設定 |
| `|` | 小節線 |
| `[: ... :n]` | リピート |
| `{ C D E }4` | 連符 |
| `(CEG)4` | インライン和音 |
| `(CEG)2:16` | 十六分音符間隔のアルペジオ |
| `(C { E F G }4)2` | 和音内連符 |

基本例:

```mml
#TIME 4/4
T120 O4 L8 V12 Q7 @gm1
C D E F | G A B > C |
```

### 音長・ゲートタイム

- `L4` は四分音符、`L8` は八分音符です。
- `C8`、`D16.`、`R4` のように個別音長と付点を指定できます。
- `C1` と `R1` は拍子に関係なく四分音符4拍分です。
- `Q1` は音符長の1/8、`Q8` は音符長いっぱいまで発音します。
- `Q` は音符が占める時間を変更せず、実際の発音時間だけを変更します。

### 音量・パン

- `V0`〜`V15` で音量を設定します。
- `cresc.` / `dim.` は以降の音符ごとに音量を1段階変化させます。
- 和音は和音全体で1段階、休符では進行しません。
- `V<number>` を指定すると `cresc.` / `dim.` を解除します。
- `P-1.0` は左、`P0` は中央、`P+1.0` は右です。
- パンは内部でMIDI互換の0〜127相当へ変換して保持します。

```mml
V8 cresc. C D E F
V12 dim. G F E D
P-1.0 C P0 E P+1.0 G
```

### タイ・スラー

- `C&C` は同じ音を1つの音として延長します。
- `C&D` は異なる音をスラーで接続します。
- 同じ音でも音色、音量、パンなどが変わる場合はスラーとして扱います。
- 休符・和音へのタイ/スラー接続には対応していません。

### 連符・和音

`{ C D E }4` は3イベントを四分音符1つ分へ均等配置します。連符内の個別音長は
無視されますが、休符や音色・音量・`Q`などの状態変更は使用できます。

`(CEG)4` はC・E・Gを同時発音します。音長を省略すると現在の `L` を使用します。
付点、臨時記号、和音内だけの `<` `>` に対応しています。

`(CEG)2:16` は和音全体を二分音符の長さに保ち、記述順に十六分音符間隔で
各音を開始します。下降アルペジオは `(GEC)2:16` のように音順で指定します。
アルペジオの各音は和音末尾までの残り時間を発音時間として扱います。

`(C { E F G }4)2` はCを二分音符ぶん保持しながら、E・F・Gを四分音符1つ分へ
均等配置します。和音内連符では音符、休符、臨時記号、`<` `>` を使用できます。
和音内連符の長さは和音全体の長さ以内である必要があります。現時点では、
アルペジオと和音内連符を同じ和音内で併用できません。

```mml
T120 O4
{ C D E }4 { F G A }4.
(CEG)2 (F>A<C)2
(CEG)2:16
(C { E F G }4)2
```

### リピート

```mml
[: C D E F :2]  // 2回
[: G A B > C :] // 回数省略時も2回
```

リピートは再生前に内部展開し、元のMML本文は変更しません。ネスト、1番括弧/
2番括弧、セーニョ、ダルセーニョ、コーダには対応していません。展開後のMMLが
200,000文字を超える場合はエラーになります。

### 拍子・小節線

- デフォルト拍子は `4/4` です。
- `#TIME 3/4`、`#TIME 6/8` などを指定できます。
- 拍子はグローバル設定で、トラック1の設定・変更を全トラックへ適用します。
- 小節長不足は内部休符で補完します。
- 小節長超過は仮想小節線を挿入します。
- 元のMML本文と長いNoteEventは分割・書き換えしません。
- 小節補正や複数トラックの小節線ずれはWARNINGとして表示します。

```mml
#TIME 3/4
L4 C D E | F G A |
```

## 音色

### 内蔵音色

`@0`〜`@15` は内蔵音色予約です。未割り当て番号は矩形波として再生します。

| コマンド | 音色 |
| --- | --- |
| `@0` | 矩形波 |
| `@1` | サイン波 |
| `@2` | 三角波 |
| `@3` | ノコギリ波 |
| `@4` | FM風ベル |
| `@5` | FM風ベース |
| `@6` | ノイズ |

### MML内FM音色

`@16`〜`@63` はMML本文内の `%fm ... %end` で定義します。定義をMML本文に
含めるため、txt/mmlファイルだけで曲と音色を持ち運べます。

2OP例:

```mml
%fm @16 name="Bell"
algorithm=0
feedback=2
op1 ratio=1.00 detune=0 level=1.00 attack=0.01 decay=0.30 sustain=0.40 release=0.20
op2 ratio=2.00 detune=0 level=0.60 attack=0.01 decay=0.20 sustain=0.00 release=0.10
%end

T120 O4 L8 @16
C E G > C
```

4OPでは `op3` と `op4` を追加します。現在の `algorithm=0` は
`op4 -> op3 -> op2 -> op1` の直列です。特定のFM音源チップとの完全互換では
なく、FM音色エディタUIは未実装です。

### GM音源風プリセット

`@gm1`〜`@gm128` はGM音源風プリセットです。Web Audio再生では内蔵波形/
簡易FMで近似し、MIDIエクスポート時にはGMプログラム番号として使用します。

```mml
T120 O4 L8
@gm1 C E G > C
@gm81 C D E G
```

プリセット調整には、SimK98/ymfmidiwinに含まれるMITライセンスのDMXOPL
`GENMIDI.op2` バンクを参考にしています。OPL値の直接移植ではありません。

## WAVエクスポート

- 44.1kHz / 16bit PCM / stereo RIFF/WAVE
- `OfflineAudioContext`を使用
- リアルタイム再生と同じSynth、音色定義、ミックス処理を使用
- リピート展開、複数トラック、拍子による内部補正を反映
- 内部では将来の5.1ch向けに最大6チャンネル分の出力ゲインを保持

4音以上が同時に発音開始する場合、ピーク集中を抑えるため、再生時とWAV
レンダリング時だけ開始時刻を最大±4 ticksへ分散します。NoteEventとMIDI出力
タイミングは変更しません。

長い曲ではファイルサイズが大きくなるため、推定サイズが50MBを超える場合は
確認ダイアログを表示します。

## MIDIエクスポート

- SMF Format 1
- コンダクタートラック先頭に `GM System On` を付与
- テンポと拍子をコンダクタートラックへ出力
- `@gm1`〜`@gm128` を指定した音符だけを出力
- GM音色を含むMMLトラックを個別SMFトラックとして出力
- Program Change、音量、パン、Note On/Offを出力
- GM Channel 10は打楽器用として予約
- 内蔵音色とMML内FM音色の音符は出力対象外

ドラム専用トラック、ピッチベンド、5.1ch情報のMIDI変換には対応していません。

## オフライン動作

本番ビルドではService Workerを登録します。初回オンラインアクセス後、アプリ
シェルと取得済みアセットをCache Storageへ保存し、オフラインでも起動できます。

開発サーバー中はService Workerを登録しません。オフライン動作は本番ビルドを
静的配信するか、GitHub Pages上で確認してください。

## 開発

Node.jsとnpmが必要です。

```bash
npm install
npm run dev
```

```bash
npm test
npm run build
```

ビルド成果物は `dist/` に生成されます。

### ソース構成

| パス | 責務 |
| --- | --- |
| `src/mml/` | MML前処理、パース、Song生成、音色レジストリ |
| `src/audio/` | 共通再生計画、リアルタイム再生、シンセ、WAV出力 |
| `src/midi/` | テンポマップ変換、SMF出力 |
| `src/ui/` | ファイル名、警告、表示形式などのUI補助 |
| `src/storage/` | localStorageとテキストファイル入出力 |
| `src/demo/` | デフォルトのデモ曲 |
| `src/app.ts` | 画面構築と各機能の接続 |

## GitHub Pagesへの配置

`vite.config.ts` の `base` はリポジトリ名 `mml-player-pwa` 用に設定しています。

```ts
base: "/mml-player-pwa/"
```

リポジトリ名を変更する場合は `"/your-repo-name/"`、カスタムドメインでルート
配信する場合は `"/"` に変更してください。

`.github/workflows/pages.yml` により、`main` ブランチへのpush時に次を実行します。

1. `npm ci`
2. `npm test`
3. `npm run build`
4. `dist/` をGitHub Pagesへ公開

Repository SettingsのPagesでSourceを `GitHub Actions` に設定してください。
